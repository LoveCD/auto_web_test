# Version Change: V1.0.1 Wi-Fi Rule Update

## 修改点

1. Wi-Fi 密码规则从 8-63 位调整为 10-63 位。
2. Wi-Fi 设置接口新增字段 `band`，默认值为 `2.4G`。
3. Wi-Fi 设置成功响应新增 `applied: true`。

## 期望 QCoder 输出

- 识别受影响用例：`TC-API-WIFI-001`、`TC-API-WIFI-003`。
- 建议新增 9 位密码拒绝用例。
- 建议更新 Wi-Fi 设置请求，增加 `band` 字段。
- 推荐执行 smoke + Wi-Fi regression。
