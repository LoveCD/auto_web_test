# 国际网关基线版本 Web 接口测试范围

## 目标

覆盖国际网关基线版本 Web 后台接口的核心回归场景，用于版本准入和快速回归。

## 首期模块

| 模块 | 接口能力 | 测试重点 |
|---|---|---|
| 登录认证 | login | 正确账号登录、错误账号拒绝、token/session 处理 |
| 状态页 | device status | 软件版本、运行时间、WAN 状态、Wi-Fi 状态 |
| Wi-Fi | get/set Wi-Fi | SSID 查询、SSID 修改、保存后查询一致 |
| WAN | WAN status | WAN 连接状态、IP 地址、连接类型 |
| 系统维护 | reboot | 重启接口返回、设备临时不可用、恢复在线 |

## 测试维度

- 正常路径
- 非法输入
- 权限/未登录访问
- 配置保存后查询一致
- 版本回归可重复执行

## MVP 指标

```text
Smoke 用例：5-8 条
核心回归用例：15-25 条
执行时间：Demo 环境 1 分钟内，真实环境目标 2 小时内
报告：JSON + Markdown
AI 工作流：用例生成、修改点更新、回归选择、失败分析、覆盖分析
```
