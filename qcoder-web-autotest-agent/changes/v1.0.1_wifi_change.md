# Version Change: V1.0.1 Wi-Fi Rule Update

## 修改点

1. Wi-Fi 密码规则从 8-63 位调整为 10-63 位。
2. Wi-Fi 设置页新增安全模式下拉框 `security_mode`（WPA2-PSK / WPA3-Personal / WPA2/WPA3）。
3. 保存按钮文案由 "Save" 改为 "Apply"（元素 id `save_wifi` 保持不变）。
4. 保存成功提示由 "Settings saved" 改为 "Wi-Fi settings applied successfully"。

## 期望 QCoder 输出

- 识别受影响用例：`TC-WEB-WIFI-001`、`TC-WEB-WIFI-003`、`TC-WEB-WIFI-004`。
- 建议新增 9 位密码拒绝用例、10 位密码通过用例。
- 建议新增安全模式选择验证用例。
- 若按钮无稳定 id，selector 由文案 "Save" 改为 "Apply"。
- 推荐执行 smoke + Wi-Fi regression。
