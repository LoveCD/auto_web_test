# 国际网关基线版本 Web 测试范围

## 目标

覆盖国际网关基线版本 Web 管理界面的核心回归场景，用于版本准入和快速回归。
被测页面源码位于 `web/web/UI/INTL/fiberweb`（html / html_new_ui 两套 UI）。

## 首期模块

| 模块 | 页面能力 | 测试重点 |
|---|---|---|
| 登录认证 | login.html | 正确账号登录、错误凭证拒绝、未登录访问拦截、登出 |
| 状态页 | status.html | 软件版本、运行时间、WAN 状态、Wi-Fi 状态与 SSID 同步 |
| Wi-Fi | wifi.html | SSID 查询/修改、密码规则（8-63）、保存后查询一致、边界校验 |
| WAN | wan.html | WAN 连接类型/状态/IP/网关/DNS/MAC 展示 |
| LAN | lan.html | LAN IP/掩码展示、DHCP 状态、非法 IP 拒绝、修改生效 |
| 系统维护 | system.html | 设备信息展示、重启操作确认与受理 |
| 固件升级 | upgrade.html | 当前/最新版本展示、非法 URL 拒绝、升级受理 |

## 测试维度

- 正常路径（登录 -> 页面加载 -> 数据展示 -> 配置保存 -> 一致性确认）
- 非法输入（超长 SSID、短密码、非法 IP、非法 URL）
- 权限/未登录访问（受保护页面重定向到登录页）
- 边界值（SSID 32/33 字符、密码 7/8/63 字符）
- 配置保存后查询一致（改 SSID 后状态页同步、改 LAN IP 后刷新保留）
- 版本回归可重复执行（用例间状态隔离，mock 可重置）
